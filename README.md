# Nepali Date Picker (Vue 3)

Monorepo for [`@versatilegurung/vue-nepali-datepicker`](packages/datepicker), a Bikram Sambat date picker for Vue 3.

| Path                  | What                                                            |
| --------------------- | --------------------------------------------------------------- |
| `packages/datepicker` | The published library ([README](packages/datepicker/README.md)) |
| `playground`          | Vite app for manual testing, uses the library source directly   |

```sh
pnpm install
pnpm --filter playground dev   # try it out
pnpm test                      # unit + component tests
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow and release process.
